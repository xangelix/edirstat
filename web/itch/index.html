eDirStat v2.2.0 — Modern, High-Performance Disk Analyzer

eDirStat is a cross-platform disk usage analyzer built from the ground up in Rust. By combining a multithreaded directory walker with a zero-copy arena allocator, it scans and visualizes disk space with minimal memory and CPU overhead.

Precompiled binaries for Windows and Linux are available exclusively here on itch.io. They are multi-CPU binaries, that include thorough optimizations for certain SIMD/SSE/AVX instructions.

Key Features

  • Work-Stealing Directory Walker: Utilizes a lock-free parallel traversal engine that distributes directory branches dynamically across your CPU cores, eliminating idle thread bottlenecks.
  • Direct NTFS MFT Scanning: On Windows and Linux, eDirStat can bypass standard OS filesystem APIs to parse the Master File Table (MFT) directly, allowing near-instantaneous indexing.
  • 7-Stage Cryptographic Deduplicator: Isolates duplicate files through a tiered filtering pipeline (Size, Prefix Hash, Midpoint Hash, Suffix Hash, Multi-Range Sampling, Full BLAKE3, and Timestamp Verification) to identify redundant files without unnecessary read operations.
  • Dynamic Visualizations: Inspect disk space using an interactive squarified treemap with breadcrumb navigation and subfolder zooming, file-type composition graphs, or duplicate grouping charts.
  • Fast Compressed Snapshots: Save directory states to compact, Zstd-compressed .edst snapshot files using a columnar v3 layout that loads in milliseconds.
  • Full Localization: Community-translated interface in 18 languages (English, Arabic, Bengali, Chinese (Simplified), Chinese (Traditional), Dutch, French, German, Hindi, Italian, Japanese, Korean, Polish, Portuguese, Russian, Spanish, Turkish, and Vietnamese) with a built-in language selector.
  • Theme System: System (auto-detected), Dark, Light, and High Contrast themes.
  • Bulk File Actions: Queue directories or individual duplicate files directly from the UI for batch trashing, permanent deletion, or replacement with hardlinks.

Platform Support

  • Windows: Windows 10/11 (64-bit). Note: Administrator privileges are required to utilize the raw NTFS MFT scanning feature.
  • Linux: Compatible with major distributions (Ubuntu, Fedora, Arch) on standard desktop environments. Note: Root privileges are required to utilize the raw NTFS MFT scanning feature; exported $MFT files can also be parsed offline on any platform.
  • macOS: macOS 12+ (Apple Silicon / aarch64).

How to Use

  1. Download: Grab the archive for your operating system below.
  2. Extract: Unpack the executable file to any folder on your machine, if you're on a portable version. If you're using the Windows installer, simply click through the steps.
  3. Run:
    • On Windows, double-click edirstat.exe (or run as administrator to enable direct MFT parsing).
    • On macOS, open the downloaded .dmg and drag eDirStat.app to your Applications folder.
    • On Linux, run ./edirstat or launch it via your terminal. You can also pass a directory path directly to target a scan immediately: 
./edirstat /path/to/scan
